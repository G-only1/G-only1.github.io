Steganography Lab

Steganography Lab

Objective:

Data can be hidden in many ways. A quick and effective method is embedding data into an image. This activity is designed to give you some basic experience with steganography. On your Windows 10 VMs, one simple method is to combine an image file and a text file into a bigger file.

Instructions:

Part 1: Appending text to an image

  1. Find a small image on the Internet, open it in MS Paint & then save it as a 24bit bitmap (bmp) named image.

Deliverable 1: Screenshot of your BMP file named “Image” next to its file size. Example shown below:

  1. Using Notepad, create a file called “SuperSecretCyberData”, and then insert:
  • “Passwords are yummy!”

Deliverable 2: Screenshot of SuperSecretCyberData’s file size.

3. Open a CMD window and combine the two files using the CMD copy command.

copy /b image.bmp + SuperSecretCyberData.txt   stego.bmp

Part 2: Examining the “stego.bmp” File

Deliverable 3: Screenshot “stego.bmp” with the image still showing when opened with Microsoft Paint.

Deliverable 4: Screenshot of “stego.bmp” in notepad, showing “Passwords are yummy!” at the bottom of the file.

Deliverable 5: Screenshot the file size of “stego.bmp” and Write how much the file size grew from image.bmp’s file size.

File explorer shows the file size of stego.bmp is the same as image.bmp. Because of this, I think the bitmap grew by only a few bytes.
