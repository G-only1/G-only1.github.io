Module 6 Class Activity - Cryptography

Cryptography

Objective:

To better understand hashing, public and private keys, and other cryptographic methods by using them.

Instructions:

Part 1 - Hashes

  1. Go to https://gchq.github.io/CyberChef/.

  2. Under “Input,” type the phrase in the screenshot below.

  3. Using the search tool, find hashes of the text for the requested algorithms by dragging the operations into the “Recipe” box. An example using Argon2 is below.

  • Deliverable 1: Show screenshots of the hashes for MD5, SHA1, and SHA2.
    MD5: fa745744e07d05158da73a10677bf0ba

    SHA1: 72d041b75f7d6c9a91e4810c69c4fe978099544a

    SHA2: 66d5764d1bee5133d0916e63dc89c4382084d54324d62b867c86947a260864a24ffbb6955460162b0f3935394a311dac48b105862bd76a3e2b26169087386475

  1. Now we’ll check the integrity of a file using hashes. On your Kali VM, download “Installer” at https://www.kali.org/get-kali/#kali-installer-images.

    Please note that I have already downloaded this for most of you. If you didn’t change the champuser password, check your downloads folder.

  1. Once that file is done downloading, open a terminal and cd to /Downloads.

  2. Run ls to make sure that the file is there.

  3. Now, run the command sha256sum followed by the name of the file. This should show you the file’s SHA256 hash.

  4. Now click the “sum” button on the site you downloaded the file from.

    • Deliverable 2: Show a screenshot of the sums. Do they match? Why or why not?
      They do not match because after the installation is complete there will always be changes from the initial state of the installation source.
      On my Kali VM:
      On the website: 6dbefacc95e3b556c19c48e8bae39b8b505e2d3a1aba0bfb7ab62b036c3d2ba3

Part 2 - Base64

  1. On your Kali VM

  2. Create two text files in the /Desktop directory using nano

  3. Name these text files part1.txt and part2.txt

  4. In the part1.txt file add the encoded text below:
    YUhSMGNITTZMeTlsYmk1M2FXdHBjR1ZrYVdFdWIzSm5MM2Rw

  5. In the part2.txt file add the encoded text below:
    YTJrdlEyOXRjSFYwWlhKZmMyVmpkWEpwZEhrPQ==

    • Deliverable 3: Take a screenshot of the output of cat command on both of your text files

  6. Open a terminal window and navigate to your /Desktop directory where your files were created

  7. Using the built in base64 command we’ll decode these parts, type the command base64 -d followed by the filename followed by an > and a new output file name

  8. Do the same for the part2 text file

    • Deliverable 4: The output of the cat command for both the newly decoded files

  9. You might notice they still seem encoded; both pieces might be double encoded!

  10. Use the first part of the command to decode our part1decoded.txt and part2decoded.txt again

  • Deliverable 5: The output of the base64 -d command for both your files
  • Deliverable 6: What do the two decoded files look like they could be?
    The decoded files look like they will form a link to a Wikipedia article if they are put together
  1. Open a browser of your choice and now combine the two url pieces to find the website
    • Deliverable 7: Take a screenshot of the website the combined url produces

Part 3 - XOR

  1. In your browser, open https://gchq.github.io/CyberChef/.

  2. On your desktop, create a file named “secret.txt”. Add the following to the contents: fDK|JPa@FW\UQh@

    • Deliverable 8: Show a screenshot of the new file and its contents.

  3. In Cyberchef, select the option “Open File as Input”. This is located in the top left.

  1. From here, select “XOR Brute Force” and add it to the Recipe column. Ensure that the Key Length is set to 1.
    • Deliverable 9: Show a screenshot of the secret message. What was the correct key?
  2. Select “Clear Input and Output”, then select “Clear Recipe.”
  3. From operations, select “XOR” and drag it to the Recipe Column.
  4. For the Key, select “HEX” and type 250. Keep the scheme as Standard. Inside Input, type “Cryptography is fun”.
    • Deliverable 10: Show a screenshot of the Cyberchef page. Be sure to include the input and output!

Part 4 - Public and Private Keys

  1. On your Windows 10 VM, go to https://www.gpg4win.org/. Click on the green download box, then select the $0 option. By default, the website will attempt to get you to pay.


  1. When installing Gpg4win, be sure to select all of the components.
  2. Once the installation is complete, open Kleopatra. Look under the File tab, then select the option “NewOpenPGP”.
  3. Enter your name and email address, ensure the option for a passphrase is selected, then click “OK”.
  4. You’ll be prompted to create a password for the key. Ensure that you will not forget it, or will it be lost.
    • Deliverable 11: Show a screenshot of your newly created key within Kleopatra, as well as a screenshot of the fingerprint assigned to it.
  5. Under File, select the option to backup your Secret Keys, then save your secret key to the Desktop. Name the file your first and last name, formatted as First_Last_SECRET. Save it.
    • Deliverable 12: Show a screenshot of your saved secret key.
  6. From here on, you’ll need a partner for the task.
  7. Export your public key (name it firstname_lastname_PUBLIC), then send it to your partner.
    • Deliverable 13: Show a screenshot of your shared public key, as well as a screenshot of the public key your partner sent.
  8. To add your partner’s public key to your program, go under File and select the option “Import”.
    • Deliverable 14: Show a screenshot of the successful addition of your partner’s public key.
  9. Create a text file and add a message saying hi to your partner. Then, use Kleopatra’s “Sign/Encrypt” feature to encrypt it with your message.
  10. When encrypting, ensure that you’ve selected your partner under “encrypt for others”. If the field is blank, they will not be able to read your message!
  11. Send your partner the encrypted message.
    • Deliverable 15: Show a screenshot of the exchanged files.
  12. In Kleopatra, select the “Decrypt” option. Ensure you’ve selected your partner’s public key to be able to decrypt the message.
    • Deliverable 16: Show a screenshot of the decrypted message!
